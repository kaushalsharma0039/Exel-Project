# Hospital Emergency Room Dashboard (Excel Project)

## Project Overview
This Excel project analyzes **Hospital Emergency Room (ER) data** to monitor patient flow, waiting time, admission status, and overall service performance using an interactive dashboard.

## Objective
- Track ER performance metrics
- Analyze patient distribution by age, gender, and department
- Identify delays and patient satisfaction trends
- Support data-driven decision-making for hospital management

## Key KPIs
- Total Number of Patients
- Average Waiting Time (minutes)
- Patient Satisfaction Score
- Admission vs Non-Admission Rate
- Patients Attended Within Time vs Delayed

## Dashboard Insights
- Monthly patient trend analysis
- Age group-wise patient distribution
- Gender-wise patient count
- Department-wise referral analysis
- Admission status comparison
- Service timeliness (Within Time vs Delay)

## Excel Features Used
- Pivot Tables & Pivot Charts
- Slicers (Month & Year filtering)
- IF formulas
- COUNTIFS / SUMIFS
- Conditional Formatting
- Data Cleaning & Structuring

## Tools
- Microsoft Excel

## Outcome
Created a clean and interactive Excel dashboard that provides quick insights into ER operations, helping improve efficiency and patient experience.
